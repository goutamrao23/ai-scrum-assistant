# AI Scrum Assistant

A practical project exploring how AI can support Scrum Masters and Agile teams with story refinement, sprint planning, and interactive Agile learning.

## Project Overview

AI Scrum Assistant is a hands-on prototype designed to bring common Scrum workflows into one place. It is being developed as a learning project using beginner-friendly, browser-based tools.

## Features Implemented

- **Dashboard:** Sprint progress, summary cards, and recent activity.
- **User Stories:** Create, edit, and delete stories, with rule-based acceptance-criteria suggestions.
- **Sprint Planning:** Define sprint goals, dates, team capacity, and selected stories, with capacity warnings.
- **Sprint Board:** Track work across To Do, In Progress, Testing, and Done.
- **Definition of Ready / Definition of Done:** Manage checklist items and completion progress.
- **RAID Log:** Record and track risks, assumptions, issues, and dependencies.

## Technology Stack

- React
- TypeScript
- Tailwind CSS
- Browser localStorage for prototype data persistence
- Bolt.new for browser-based development

## Current Status

The prototype's core Scrum modules have been implemented and manually tested, including persistence after browser refresh. Acceptance-criteria suggestions currently use rule-based logic; generative AI integration is a future enhancement.

## Roadmap

## Learning Goals

- Apply Scrum practices to a working software prototype.
- Explore practical AI use cases for Agile teams.
- Build product thinking, workflow design, and iterative delivery skills.

This is an independent learning prototype. Sample banking scenarios are fictional and are not connected to a real banking system.
